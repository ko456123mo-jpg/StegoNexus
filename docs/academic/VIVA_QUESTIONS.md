# StegoNexus — أسئلة المناقشة (VIVA) وإجاباتها النموذجية

> 4 أسئلة × 6 درجات (حسب معايير التقييم). هذا الملف يجهّز الطالب للإجابة على
> الأسئلة الأربعة المنتظرة حول المشروع والأداة، مع الإشارة إلى مكان كل موضوع
> داخل StegoNexus بحيث تكون الإجابة **مقرونة بعرض حي مباشر** من البرنامج.

---

## السؤال 1 — الإخفاء والاستخراج في الصور (القضية التي جرت في العملي)
**«اشرح تقنية إخفاء البيانات داخل الصور، وكيف تقوم بالاستخراج، وما الأدوات/الطرق التي استخدمتها؟»**

### الإجابة النموذجية:
1. **Steghide (أداة Kali):** تدمج الملف السري داخل الصورة (JPEG/BMP) بعد ضغطه
   وتشفيره بخوارزمية Rijndael-128 في وضع CBC. الاستخراج يتم بنفس كلمة المرور:
   - `steghide embed -cf cover.jpg -ef secret.bin -p pass`
   - `steghide extract -sf stego.jpg -p pass`
2. **CyberHide (تنفيذ خاص داخل StegoNexus):** لكل صورة PNG نقوم بما يلي:
   - تشفير السر بـ **AES-256-CBC** بمفتاح مشتق من كلمة المرور (PBKDF2-HMAC-SHA256).
   - إضافة **HMAC-SHA256** للتحقق من صحة كلمة المرور عند الاستخراج (رفض المفتاح الخاطئ).
   - إخفاء البتات في **قنوات RGB (LSB)** مع **تبديل مواضع مبني على المفتاح**
     (Keyed Permutation) حتى لا يمكن لأحد إعادة التجميع بدون المفتاح.
3. **الاستخراج هو العملية العكسية** بنفس المفتاح، والتحقق من HMAC قبل محاولة فك التشفير.
4. **الكشف:** `steghide info` يعرض البيانات المخفية (اسم الملف، الحجم، التشفير)
   عند إدخال كلمة المرور الصحيحة، ورفض كلمة مرور خاطئة دليل وجود بيانات مخفية.

### العرض الحي:
```
python run_cli.py image demo_output/cover_photo.png demo_output/secret.txt --password s3cret
python run_cli.py image-unhide demo_output/cover_photo_embedded.jpg --password s3cret
python run_cli.py image-info demo_output/cover_photo_embedded.jpg --password s3cret
```
أو من الواجهة: **Image → Hide / Extract / Probe / Metadata**.

## السؤال 2 — الإخفاء في الصوت: أكثر من تقنية (LSB / Phase / Spread Spectrum / Metadata)
**«ما الفرق بين LSB و Spread Spectrum في إخفاء الصوت؟ ولماذا نستخدم أكثر من تقنية؟»**

### الإجابة النموذجية:
- **LSB:** نستبدل أقل بت أهمية في عينات الصوت ببتات الرسالة. بسيط وسريع وشفاف،
  لكنه ضعيف أمام الضغط والتشويش (البتات قد تُتلف في MP3/AAC).
- **Spread Spectrum (DSSS-BPSK):** ننشر كل بت من الرسالة على مدى طيف واسع
  (مثلاً كل بت × 64 شريحة بتسلسل PN مشتق من المفتاح) ثم نضيفه للإشارة بمقدار
  صغير. أكثر قوة ضد الضوضاء والقطع الجزئي، لكنه يحتاج معالجة أكثر.
- **Phase Coding:** نعدّل معلومات الطور (الفرق ±π/2 بين إطارات FFT متتالية)
  بدل السعة — يصعب على الأذن اكتشافه، لكنه حساس لمزامنة الملفات.
- **Metadata:** نخفي البيانات في حقول RIFF LIST-INFO (ICMT) **دون لمس العينات**
  نفسها — حجم أكبر وسرعة، لكن أي إعادة ترميز تحذفه (سهل الكشف).
- **لماذا أكثر من تقنية؟** كل تقنية لها مزايا وعيوب؛ وجود أكثر من تقنية =
  اختيار الأنسب حسب الوسط (أكثر إخفاءً، أكثر ثباتاً…) وهذا هو مضمون المتطلب
  «كل موضوع إخفاء يمكن تطبيقه بأكثر من تقنية».

### العرض الحي (4 أوامر):
```
python run_cli.py audio lsb      wav demo/cover.wav secret.bin --key K
python run_cli.py audio phase    wav demo/cover.wav secret.bin --key K
python run_cli.py audio ss       wav demo/cover.wav secret.bin --key K
python run_cli.py audio meta     wav demo/cover.wav secret.bin --key K
python run_cli.py audio-unhide lsb wav demo/cover_lsb.wav --key K
```

## السؤال 3 — الإخفاء في الشبكة (قنوات خفية) والفيديو
**«كيف يتم إرسال بيانات مخفية عبر الشبكة؟ وكيف يحدث الإخفاء في الفيديو؟»**

### الإجابة النموذجية:
**الشبكة (Covert Channels):** نستغل حقولاً في بروتوكولات TCP/IP لا يستخدمها
التطبيق أو لا يفحصها عادة:
1. **IPv4 Identification (IP-ID) LSB:** نبّت واحدة من حقل معرف الحزمة (16 بتاً).
2. **TCP Initial Sequence Number (ISN) LSB:** بت داخل الرقم التسلسلي الأول.
3. **Timing Channel:** بت في الفارق الزمني بين الحزم (تأخير صغير/كبير).
- التطبيق: **Sender** يبني الحزم (Ethernet/IPv4/TCP يدوياً عبر مكتبة PCAP خاصّة)،
  والبيانات تُشفَّر أولاً وتُوزَّع بتبديل مفتاحي على الحزم.
- **Receiver** يجمع الحزم، يزيل التبديل بالمفتاح، يعيد التجميع، ويفك التشفير.
- **الكشف:** محلّل مدمج يفحص أنماط LSB المتوازنة غير المتناوبة (سلوك حقيقي ≠
  اختباري) وأنماط التأخير ثنائية النمط.

**الفيديو:** ثلاث تقنيات:
1. **Video LSB:** نسحب المسار الصوتي عبر `ffprobe` ثم `ffmpeg` إلى WAV، نخفي
   فيه بـ LSB، ثم نعيد الدمج **بنسخ الإطارات البصرية كما هي** (`-c:v copy`)
   في حاوية PCM/MKV — الصورة لا تتغير إطلاقاً (الترميز المفقود مثل AAC يدمّر
   البتات، لذا نستخدم PCM).
2. **Container Hiding:** إلحاق حمولة مشفّرة بتذييل موقّع بالمفتاح داخل ملف الفيديو.
3. **Spread Spectrum:** نشر البيانات على المسار الصوتي كما في الصوت.
- والاستخراج عكسي، مع `videohide.sh` الذي يوضح خطوات FFmpeg/FFprobe منفصلة.

## السؤال 4 — البرامج الضارة: التخفي والتهرب + التحليل الجنائي والهاش
**«اذكر تقنيات إخفاء/تهرب البرامج الضارة، وكيف تحلل ملفاً مشبوهاً؟»**

### الإجابة النموذجية:
**تقنيات الإخفاء والتهرب (Hiding & Evasion):**
- **التغليف/الضغط:** PyInstaller (بصمة `MEI\014\013` و `PYZ` في .exe)،
  WinRAR SFX (`Rar!`)، أدوات التشفير/التغليف (Packers) — تُظهرها **إنتروبيا
  الأقسام > 7.0** في ملفات PE/ELF.
- **الأطر:** Metasploit (`msfvenom`/`meterpreter`)، Sliver — بصمات موقّعة
  تُفحص عبر باحث الأنماط المدمج.
- **Overlay:** بيانات ملحقة بعد نهاية قسم التنفيذ (مخبأ شائع للحمولات).

**التحليل الجنائي (Forensics & Analysis):**
1. `file` — النوع الحقيقي من الترويسات (كشف الإخفاء بالتغيير).
2. `strings` — نصوص قابلة للقراءة والكلمات المفتاحية (رابط، أوامر…).
3. `exiftool` — البيانات الوصفية (المؤلف، التعليقات، GPS…).
4. `binwalk` — التوقيعات والملفات المدمجة (Files).
5. `steghide info` — تأكيد الحمولة.
6. `foremost` — استخراج الملفات المدمجة (Carving).
7. `zsteg` — تحليل طبقات LSB في الصور.
8. **Shannon Entropy** — قياس العشوائية (نافذة منزلقة تعلّم المناطق المشبوهة).

**الهاش (Hashing & Integrity):** حساب MD5/SHA-1/SHA-256/SHA-512 للملفات
للتحقق من التلاعب، ومقارنة النسخ قبل وبعد العمليات، وإلحاق القيمة بملف القضية.

### العرض الحي:
```
python run_cli.py malware sample.exe          # PE/ELF + بصمات
python run_cli.py forensics file.jpg --password pw
python run_cli.py hash file.iso -a MD5 SHA-256 SHA-512
```

## أسئلة إضافية محتملة (تدريب)
| السؤال المحتمل | مكان الإجابة |
|---|---|
| ما الفرق بين steganography و cryptography؟ | إخفاء وجود الرسالة مقابل إخفاء محتواها؛ StegoNexus يجمع الاثنين (تشفير + إخفاء) |
| لماذا لا نحتاج أداة واحدة فقط؟ | كل أداة/تقنية لها نقطة قوة؛ Dashboard تدمج ما أُخذ في الترم وتوفّر التبادل |
| كيف تتأكد أن الملف الناتج سليم؟ | هاش قبل/بعد + فحوصات استخراج تلقائية في الاختبارات (59 فحصاً) |
| ماذا يحدث إذا غابت أداة من أدوات Kali؟ | بديل مدمج بـ Python يعمل تلقائياً (Pillow/المكتبات) والأداة لا تتوقف |
| أين تُحفظ النتائج؟ | القضية النشطة: `reports/` (MD/JSON/HTML) + `logs/investigation.log` |
